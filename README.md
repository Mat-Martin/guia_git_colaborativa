# guia_git_colaborativa
# Guía colaborativa de Git Este repositorio es un ejercicio práctico para aprender Git en parejas. 
## Objetivo Aprender a usar ramas y merges.
## Conceptos básicos de Git
- Repositorio
- Commit
- Rama
- Merge
## Flujo de trabajo básico
1. Editar archivos
2. git ASD
3. git commit
4. git push
## Áreas del Departamento
El Departamento está a cargo de 3 temas:
- Formación de especialistas (ley médica)
- Relación Asistencial Docente
- Investigación en seres humanos
